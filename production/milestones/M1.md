## Milestone Goal

모든 Foundation-layer Autoload가 구현·테스트 완료되고, Core 게임플레이 루프(이동→전투→포탈)가 저장/로드 포함 완전히 동작한다. 이 밀스톤 완료 시 첫 외부 플레이테스터에게 빌드를 배포할 수 있는 최소 기준이 확보된다.

## 성공 기준 (Exit Criteria)

M1이 완료되었다고 판단하려면 다음이 모두 참이어야 합니다:

### 코드 품질
- [ ] Foundation layer 전체 Autoload GUT 테스트 PASS (CI green)
- [ ] Core layer 모든 Logic/Integration 스토리 GUT 테스트 PASS
- [ ] CI/CD GitHub Actions 전체 green

### 기능 완성
- [ ] 새 게임 시작 → 이동 → 전투(적 3명) → 동료 대화 → 포탈 전환 완전 동작
- [ ] SavePoint → 저장 → 재시작 → Continue → 파티 구성 + 씬 위치 복원
- [ ] 동료 1명 영입 후 저장 → 재시작 → 동료 파티에 존재

### 플레이테스트
- [ ] 플레이테스트 ≥2회 (M1 scope 내에서) — `production/playtests/` 기록
- [ ] **Pillar 3 첫 검증 시도**: 팀 구성에 따른 패스 잠금 해제 프로토타입 1개 이상

### 문서
- [ ] 모든 구현된 시스템의 GDD가 최종 구현과 일치 (편차 기록 포함)
- [ ] ADR-0007 SaveManager 구현 완료 확인 기록

## 위험 요소

| 위험 | 영향 | 완화 |
|---|---|---|
| Foundation Autoload 상호 의존성이 예상보다 복잡 | 스프린트 지연 | 각 Autoload 독립 테스트 후 통합 |
| SaveManager 계약이 각 Autoload 수정 공수 증가 | 1~2 스프린트 추가 | ADR-0007 계약 범위 SAVE_VERSION=1으로 엄격 제한 |
| Core 레이어 스토리가 Foundation 완성 전 블로킹 | 병렬 진행 불가 | Foundation 우선 완료 원칙 유지 |
