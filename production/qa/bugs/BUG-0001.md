# BUG-0001 — SceneTransitionManager push_warning/push_error discrepancy

**Severity**: S4 — Trivial
**Priority**: P3 — Backlog
**Status**: Open
**Reported**: 2026-05-05
**Reporter**: qa-lead (Session B TC-5)

## Summary

ADR-0003 specifies `push_error` for the case where `SpawnPoint_Default` is missing in a destination scene. The source implementation (`scene_transition_manager.gd`) uses `push_warning`. No runtime impact — the fallback to Vector2.ZERO executes correctly either way.

## Reproduction

1. Transition to any scene with no nodes in the `"spawn_points"` group.
2. Observe the Godot Output panel.

**Expected** (per ADR-0003): red `push_error` log entry.
**Actual**: orange `push_warning` log entry.

## Files Affected

- `src/core/scene_transition_manager.gd` — line ~196 (`_resolve_spawn_position`)
- `docs/architecture/adr-0003-scene-map-ui-overlay-contract.md` — line 69

## Notes

ADR-0003 also documents `get_tree().paused` while the implementation uses `PROCESS_MODE_DISABLED`. Fix both discrepancies in one pass.
