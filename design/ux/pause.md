## Purpose & Player Need

일시정지 화면은 플레이어가 게임플레이를 중단하고 저장, 설정 조정, 또는 메인 메뉴 복귀가 필요할 때 사용하는 오버레이다. 플레이어가 원하는 것: "지금 하던 것을 멈추고 빠르게 필요한 작업을 처리한 뒤 돌아오기."

접근성 요건(Basic 티어): 대화·컷씬·튜토리얼을 포함한 **모든 상태에서 언제든지 일시정지** 가능.

---

## Player Context on Arrival

플레이어는 게임플레이 중 자발적으로(Esc / 게임패드 Start) 이 화면에 도달한다. 배경에 게임 월드가 딤 처리된 채로 보이며, 플레이어는 자신이 어디서 멈췄는지 인식하고 있다. 감정 상태: 잠시 중단, 목적이 있음 (저장, 설정, 종료 중 하나).

---

## Navigation Position

`게임플레이 씬 → [Pause 오버레이]`

Pause는 씬 전환이 아닌 CanvasLayer 오버레이로 구현 (ADR-0003 기준 CanvasLayer layer=10). 게임 월드는 배경에 유지되며 딤 처리.

대체 진입 없음 — 게임플레이 씬에서만 진입 가능.

## Entry & Exit Points

### Entry

| Entry Source | Trigger | 플레이어가 가져오는 컨텍스트 |
|---|---|---|

| 대화 중 | Esc 키 / 게임패드 Start 버튼 | DialogueManager 활성 상태 유지 — 재개 시 대화 복귀 |

| Exit Destination | Trigger | 비고 |
|---|---|---|

| 게임플레이 복귀 (저장 후) | 저장 버튼 확정 | 저장 완료 후 자동 복귀 |
| 설정 화면 | 설정 버튼 | 가역적 — Back으로 Pause 복귀 |
| 메인 메뉴 | 메인 메뉴 버튼 | 미저장 진행 손실 경고 팝업 필수 |
| 게임 종료 | 종료 버튼 | 미저장 진행 손실 경고 팝업 필수 |

## Layout Specification

### Information Hierarchy

1. 재개 (Resume) — 가장 빠른 탈출구, 첫 포커스
2. 저장 (Save) — 전투 중이면 비활성
3. 볼륨 설정 — 인라인 확장 (슬라이더 펼침)
4. 설정 (Settings) — 전체 설정 화면 이동
5. 메인 메뉴 — 위험 액션 (손실 경고)
6. 종료 (Quit) — 위험 액션 (손실 경고)

### Layout Zones

센터 모달 오버레이. 배경은 게임 월드 딤 처리(불투명 패널 또는 블러).

## States & Variants

| State | Trigger | 변경 사항 |
|---|---|---|
| **기본 (탐색 중)** | 전투 외 상태에서 진입 | 저장 버튼 활성, 재개가 첫 포커스 |
| **전투 중** | 전투 중 진입 | 저장 버튼 비활성(grayed), "전투 중 저장 불가" 툴팁 |
| **볼륨 확장** | 볼륨 설정 버튼 선택 | 모달 높이 확장, 슬라이더 3개 인라인 표시 |
| **경고 팝업** | 메인 메뉴 / 종료 버튼 선택 | 경고 팝업 오버레이, 배경 추가 딤 |
| **저장 중** | 저장 버튼 확정 | 저장 버튼 텍스트 → "저장 중…", 저장 버튼만 비활성(중복 방지), 다른 버튼은 정상 동작 유지 |
| **저장 성공** | `SaveManager.save()` 완료 | 저장 버튼 텍스트 → "저장 완료 ✓" 0.8초 표시 후 Pause 자동 닫힘, 게임플레이 복귀 |
| **저장 실패** | `SaveManager.save()` IO/예외 오류 | 저장 버튼 원복, 버튼 하단 인라인 에러 1줄 표시 — "저장에 실패했습니다. 다시 시도해 주세요." (진행 손실 없음) |

### 저장 실패 상세

**저장 실패** (Save 버튼 확정 후 IO/예외 오류)
- 저장 버튼 텍스트 원복 ("저장")
- 버튼 하단 인라인 에러 텍스트 표시: "저장에 실패했습니다. 다시 시도해 주세요."
- Pause 메뉴는 그대로 유지 — 플레이어가 현재 플레이 상태를 잃지 않았음을 인지
- 3초 후 에러 텍스트 페이드 아웃, 저장 버튼 재활성
- 포커스: 저장 버튼으로 복귀 (재시도 유도)

## Transitions & Animations

**Pause 진입**: 게임 월드 즉시 정지(`get_tree().paused = true`), 모달 페이드 인 (0.15초). 배경 딤 패널 페이드 인 동시.

**Pause 퇴장 (재개)**: 모달 페이드 아웃 (0.15초), `get_tree().paused = false`.

**볼륨 확장**: 모달 높이 애니메이션 확장 (0.1초). 모션 감소 모드 시 즉시 표시.

**모션 감소 모드**: 모든 페이드/확장 애니메이션 즉시 전환으로 대체.

## Accessibility

**접근성 티어**: Standard (committed)

**언제든지 일시정지**: 대화·컷씬·튜토리얼 포함 모든 상태에서 Esc / Start 버튼으로 Pause 진입 가능 (Basic 필수 요건).

**키보드 탐색**: Tab / ↑↓ — 재개 → 저장 → 볼륨 → 설정 → 메인 메뉴 → 종료 (순환). 볼륨 확장 시 슬라이더가 탐색 순서에 포함.

**게임패드 탐색**: D-pad ↑↓ 버튼 이동, D-pad ←→ 슬라이더 조절, A버튼 확정, B버튼 / Start = 재개.

**포커스 표시**: 모든 버튼 및 슬라이더에 포커스 인디케이터 필수.

**비활성 저장 버튼**: 색상 + 불투명도 감소 병행. "전투 중 저장 불가" 툴팁은 포커스 시 스크린 리더에 읽힘.

**볼륨 슬라이더 접근성**: 독립 볼륨 조절 (음악/SFX/UI) — Basic 티어 필수 요건. 일시정지 메뉴에서 직접 접근 충족.

## Acceptance Criteria

- [ ] Esc 키 / 게임패드 Start로 게임플레이 모든 상태(탐색 중, 전투 중, 대화 중)에서 Pause 진입이 된다
- [ ] 전투 중 Save 버튼이 비활성(grayed out) 상태이며 선택되지 않는다
- [ ] 전투 외 상태에서 Save 선택 시 저장이 완료되고 자동으로 게임플레이로 복귀한다
- [ ] 볼륨 설정 선택 시 슬라이더 3개(음악/SFX/UI)가 인라인 확장되고, 슬라이더 조작 시 볼륨이 실시간 반영된다
- [ ] 메인 메뉴 / 종료 선택 시 경고 팝업이 등장하고 "취소" 선택 시 Pause 화면으로 복귀한다
- [ ] Esc / B버튼으로 Pause를 닫고 게임플레이로 복귀한다
- [ ] Tab / ↑↓ 키보드 탐색만으로 모든 버튼과 슬라이더에 접근할 수 있다
- [ ] D-pad ↑↓ + A버튼만으로 게임패드 탐색 및 선택이 완전히 동작한다 (Steam Deck 기준)
- [ ] 모션 감소 모드 활성화 시 모달 페이드 애니메이션이 즉시 전환으로 대체된다
